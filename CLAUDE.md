## О проекте

**airsoft_kitfinder** — сервис подбора снаряжения/комплектов для страйкбола (airsoft):
пользователь находит заранее собранный админом «кит» и покупает всё его содержимое
(MVP — агрегатор со ссылками на внешние магазины). Личный проект.

Проектная документация — в `docs/` (**читать перед работой над задачей**):
- [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md) — утверждённые требования;
- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — модель данных, парсеры, API, фронт, auth;
- [`docs/ROADMAP.md`](docs/ROADMAP.md) — этапы MVP и их статусы (**обновлять статус
  этапа после его завершения**).

## Стек и структура

- **Бэкенд:** Python 3.12+, FastAPI. Каталог `backend/`.
- **Фронтенд:** React + Vite + TypeScript. Каталог `frontend/`.

```
backend/
  app/            # код приложения (main.py — точка входа FastAPI)
  tests/          # pytest
  pyproject.toml
frontend/
  src/
  package.json
```

## Команды

Бэкенд (из `backend/`, пакетный менеджер — `uv`):

- Установка зависимостей: `uv sync`
- Запуск дев-сервера: `uv run uvicorn app.main:app --reload`
- Тесты: `uv run pytest`
- Линтер: `uv run ruff check .` и `uv run ruff format --check .`

Фронтенд (из `frontend/`):

- Установка: `npm install`
- Дев-сервер: `npm run dev`
- Сборка: `npm run build`

## Стиль кода (Python)

- Линтер/форматтер — **ruff** (конфиг в `pyproject.toml`).
- **Type hints обязательны** — для аргументов, возвращаемых значений и локальных переменных
  в функциях. Всегда указывай `-> Type`.
- Краткий docstring для нетривиальных функций (что делает, не как).
- После правок проверяй синтаксис: `python -m py_compile path/to/file.py`.
- Секреты — только через переменные окружения / `.env` (в git не коммитится).
