# airsoft_kitfinder — реестр магазинов для парсинга

Список магазинов-источников и их статус. Архитектура парсеров плагинная
(см. [ARCHITECTURE.md](ARCHITECTURE.md)), поэтому список расширяемый.
Разведка проведена 2026-07-16 (статусы могут меняться).

Обозначения рендера: **static** — товары в исходном HTML (httpx + selectolax);
**JS** — нужен headless-браузер (Playwright); **?** — требует проверки.

## Сложные (нужен Playwright — JS-анти-бот)

httpx получает только заглушку-челлендж; реальный браузер проходит проверку и ставит куку.
Плагинная архитектура это поддерживает: парсер-подкласс `ShopParser` может использовать
Playwright вместо httpx (реестр/ingest не меняются).

| Магазин | URL | Детали |
|---|---|---|
| AirsoftStore | airsoftstore.ru | **VirtueMart (Joomla)**. JS-анти-бот (`get_jhash` ставит куку → редирект на www). После прохождения товары рендерятся server-side. Категории — слаги без префикса: `/oruzhie`, `/oruzhie/ak-seriia`, `/snariazhenie`, `/zapchasti-i-tiuning`, `/odezhda`, `/raskhodnye-materialy`. Карточка: `.thumbnail`; цена `.newprice`; ссылка `a[href^="/<категория>/…"]`; картинка `/components/com_virtuemart/shop_image/product/…`. Пагинация `?limit=48&limitstart=N` или `?showall=999999` (все товары одной страницей). `external_id` — из слага (data-id нет). Подход: Playwright один раз получает куку челленджа → далее можно httpx с этой кукой, либо полный обход в браузере. |
| Airsoft-RUS | airsoft-rus.ru | Cloudflare-челлендж («Just a moment…», 403 для httpx). Нужен Playwright либо обход CF; браться в последнюю очередь |
