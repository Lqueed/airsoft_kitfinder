# airsoft_kitfinder — требования

Дата фиксации: 2026-07-16. Статус: утверждены, MVP в разработке.

## Суть продукта

Сервис, где пользователь находит готовый страйкбольный «кит» — заранее собранный набор
снаряжения (привод, обвес, форма, защита и т.д.) — и может купить всё его содержимое.
Киты собираются администратором заранее и хранятся в системе.

## Функциональные требования

### 1. Покупка — гибридная модель

- **MVP:** сервис — агрегатор. Для каждой позиции кита показываются предложения внешних
  магазинов (цена, наличие, ссылка); покупка совершается на стороне магазина.
- **После MVP:** собственная корзина/заказы. Архитектура не должна этому мешать
  (единица покупки — оффер магазина, `offer_id`).

### 2. Источник данных — парсинг магазинов

- Периодический (раз в сутки, ночью) парсинг сайтов страйкбольных магазинов:
  карточки товаров, цены, наличие.
- Первые кандидаты: **airsoft-rus.ru**, **strikeplanet.ru**, **airsoftstore.ru**.
  Список гибкий — архитектура парсеров плагинная, добавление магазина = один модуль.
- Желательно хранить историю цен (для будущих графиков/алертов).
- Устойчивость к смене вёрстки: битая карточка не валит прогон; аномально малый объём
  результата не приводит к массовой деактивации товаров.

### 3. Поиск кита — три способа

1. **Каталог с фильтрами**: роль (штурмовик/снайпер/пулемётчик/…), бюджет,
   тип привода (AEG/GBB/spring/HPA).
2. **Визард-опросник**: пошаговый подбор «опыт → роль → бюджет» → рекомендованные киты.
3. **Текстовый поиск**: по названию/описанию кита и названиям товаров его состава,
   терпимый к опечаткам.

### 4. Модель кита — позиции двух типов

- **Жёсткая (`fixed`)**: конкретный товар/модель (например, «CYMA CM.610»); сервис
  находит его в разных магазинах и сравнивает цены.
- **Гибкая (`flexible`)**: категория + критерии (например, «любая сетчатая маска
  до 3000 ₽»); пользователю предлагается несколько подходящих вариантов на выбор.
- Пользователь видит суммарную стоимость кита: вилку мин/макс и пересчёт по выбранным
  вариантам.

### 5. Админка с UI

- Веб-интерфейс: создание/редактирование китов, добавление позиций обоих типов,
  привязка товаров (автокомплит), публикация (черновик → опубликован).
- Разбор несматченных офферов: привязка оффера магазина к каноническому товару.
- Доступ — только у администратора (логин по паролю).

### 6. Пользователи

- **Без регистрации в MVP**: каталог, визард и поиск доступны анонимно.
- Избранное, сохранённые подборы, аккаунты — после MVP.

## Нефункциональные требования

- **БД:** PostgreSQL.
- **Стек:** Python 3.12+ / FastAPI (backend), React + Vite + TypeScript (frontend).
- Личный проект одного разработчика: простые, надёжные решения, без микросервисов,
  очередей и оркестрации.
- Документация и комментарии — на русском.

## За рамками MVP (осознанно отложено)

- Собственная корзина и заказы (схема БД готова к расширению).
- Регистрация пользователей, избранное.
- UI-мерж дублей товаров (в MVP — перепривязка офферов).
- Графики истории цен (данные копятся с первого прогона парсера).
- Алерты на падение цены.
- Полноценный полнотекстовый поиск с ранжированием.
- Киты от сообщества с модерацией.
